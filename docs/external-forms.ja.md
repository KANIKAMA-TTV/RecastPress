# 問い合わせフォームの外部サービス推奨

決定日・調査日：2026-10-26（日本時間）。D23-01としてユーザー承認済み。導入・動作検証は未実施。

## 1. 採用方針

問い合わせフォームはCMS本体から分離し、**Tallyを第一推奨**とする。サイト独自のフォームデザインを維持したい場合は、**Web3Formsを代替候補**として案内する。サービスの利用を強制するものではない。

RecastPressはリンク・埋込み・外部送信先への置換手順と、移行診断時の案内を用意する。受付の中継、フォーム用のSMTPサーバー、メール配送処理、問い合わせデータの保管は持たない。利用者がサービスを直接契約・設定し、データを管理する。R29のコメント通知の送信基盤は別の未決事項として維持する。

## 2. 候補と条件

| 候補 | 調査日時点の無料条件 | 配置方法・位置づけ |
| --- | --- | --- |
| Tally | フォーム・回答数は原則無制限（フェアユース条件あり）。管理者への通知は無料。送信者への自動返信、通知文面の変更は有料 | 第一推奨。外部フォームへのリンク、または埋込み。フォーム作成・回答管理・通知をサービスに任せる |
| Web3Forms | 月250件。自動返信・添付・ドメイン制限などは有料。上限超過後は翌月まで新規受付停止 | 独自デザイン向けの代替。ブラウザーのHTMLフォームからサービスへ直接POSTする |
| Formspree | 月50件 | 比較候補。HTMLフォームから直接送信できるが、無料枠が小さいため第一推奨にはしない |

料金・無料枠・規約は変更され得るため、案内・導入時に公式情報を再確認する。メール通知の到達保証はしない。受付結果はサービス側の回答管理画面でも確認する。

## 3. 導入とデータ管理

Tallyは、利用者がアカウントとフォームを作成し、管理者通知を有効化して、フォームへのリンクまたは埋込みコードをサイトに配置する。公開時PHPを使わず、問い合わせ内容がRecastPressを経由しない構成とする。埋込み時の表示・送信・完了表示と、通知の受信を公開前に確認する。

Tallyは通信時・保存時の暗号化と欧州でのデータ保存を公表し、無料のreCAPTCHAを提供している。これは安全性や法令適合の保証ではない。外部事業者へのデータ預託として、利用者が収集項目、保存先・保存期間・削除方法、プライバシー案内を確認する。

WordPress向けの第三者製プラグイン「Embed for Tally」は存在するが、RecastPressでの互換性・安全性は未検証。製品の標準推奨はプラグイン不要のリンク・埋込み手順とし、同プラグインの対応保証や移植は採用しない。

既存フォームは、元のPHP処理・ショートコードがそのまま動作するとは案内せず、外部フォームへの置換が必要と診断する。過去の問い合わせデータの移行・保管・削除手順は今回の決定に含めず、未決として残す。

## 4. 利用者向け案内文

> お問い合わせフォームには、外部フォームサービスのTallyを推奨します。無料プランでフォーム作成・回答管理・管理者へのメール通知を利用でき、SMTP設定は不要です。作成したフォームへのリンク、または埋込みで設置してください。サイト独自のフォームデザインを使う場合は、Web3Formsも選択できます。サービスの契約・設定・問い合わせデータの管理は、サイト運用者が行います。
