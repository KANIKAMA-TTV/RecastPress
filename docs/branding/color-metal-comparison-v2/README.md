# RecastPress colour and plating comparison

One sheet: official WordPress reference at top left, 10 flat background colours, and 13 metal treatments.

Open all-options.html. Each card links to the standalone SVG or official reference PNG. PNG exports are included.

M1–M3 preserve the earlier material options. M4–M10 add metal grounds with solid white or dark lettering. M6–M13 introduce harder chrome, black chrome, copper plating, gold plating and black nickel. Solid paint is applied to letter, annular band and stream together.

All RecastPress marks preserve concept v14 glyph, stream, cut and circular-frame geometry. WordPress is an unchanged official reference from https://wordpress.org/about/logos/ .
